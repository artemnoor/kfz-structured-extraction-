# Сверка КФЗ — Structured Extraction

Демонстрационное веб-приложение первого этапа системы сверки КФЗ: преобразование готовых результатов Document Parser в нормализованные структурированные данные с прослеживаемостью до исходного фрагмента.

## Что работает

- Демонстрационный набор согласованных результатов парсинга: КФЗ, договор, акт, счёт, дополнительное соглашение и реестр.
- Классификация документа по содержимому парсерного JSON.
- Извлечение реквизитов, дат и периодов, организаций, сумм, количеств, единиц измерения, таблиц и всех проверяемых строк КФЗ.
- Нормализация дат, сумм через decimal-строки, единиц измерения и идентификаторов; исходные значения сохраняются рядом с нормализованными.
- Provenance для извлечённых значений: документ, страница, координаты PDF или адрес ячейки XLSX, исходный текст и уверенность.
- Просмотр демонстрационных страниц и таблиц с переходом к источнику, просмотр JSON парсера и результата извлечения, экспорт результата в JSON.
- HTTP API и постоянное хранение результатов через слой Data Storage и базу D1.

## Границы демо

Распознавание исходных PDF, DOCX, XLSX и сканов здесь не реализовано. Документы в приложении — синтетические демонстрационные данные с заранее подготовленными результатами парсинга. Можно выбирать их или импортировать готовый JSON парсера. Приложение не выполняет Document Linking, финансовую сверку, расчёты и заключения; внешние LLM API не используются.

## Архитектура

| Компонент | Расположение |
| --- | --- |
| Mock Document Parser и демонстрационные результаты | `lib/parser/`, `data/parser-results/` |
| Классификация, схемы и Structured Extraction | `lib/extraction/` |
| API | `app/api/` |
| Хранение и схема базы данных | `lib/storage.ts`, `db/`, `drizzle/` |
| Пользовательский интерфейс | `app/page.tsx`, `components/` |
| Эталонные проверки | `tests/` |

Frontend и API реализованы на TypeScript/JavaScript; типы выходных данных валидируются расширяемыми Zod-схемами. Источник развёрнут как Vinext-приложение для Cloudflare Workers с D1.

## Локальный запуск

Требуется Node.js `>=22.13.0`.

```bash
npm run install:ci
npm run dev
```

Для production-сборки:

```bash
npm run build
```

Проверки:

```bash
npm test
npm run test:api
```

Локальная работа с D1 использует Miniflare. Параметры привязки и миграции находятся в `.openai/hosting.json` и `drizzle/`.
